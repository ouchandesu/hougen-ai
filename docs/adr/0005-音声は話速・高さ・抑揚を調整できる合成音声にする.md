# 0005: 音声は話速・高さ・抑揚を調整できる合成音声にする

- ステータス: Accepted
- 実装状況: 未実装（音声の経路はまだ無い — index.html, api/）
- 決定: 読み上げは録音ではなく合成音声で行い、話速・高さ・抑揚（トーン）をキャラクターごとに設定でき、語ごとのアクセントを指定できる音声エンジンを使う

## コンテキスト

放送局の要望は、標準語を入力するとナレーターが伊予弁で読み上げること、キャラクターに方言を喋らせることの 2 つ。
キャラクターのイメージの一例は「低くてゆっくり喋る」で、スピード・トーン・高さを変えたいとされている。
一般的な音声合成は標準語（東京式）のアクセントで読むため、伊予弁の文字を渡しても抑揚は標準語になる。
キャラクターの声の権利（キャラクター・声優）と月額予算は、放送局と相談中で決まっていない。

## 決定

1. 音声は合成音声で作る。変換結果のように、利用者が入力した任意の文章を読めることを優先する。
2. キャラクターは「話速・高さ・抑揚（トーン）・音量」の設定値の組として持つ。値の範囲は音声エンジン側の制約に合わせる。
3. 音声エンジンは、語ごとのアクセント（音の高低の位置）を外から指定できるものに限る。
   アクセントの正は ADR 0004 の監修済み辞書から渡す。辞書に無い語はエンジンの推定に任せ、未監修として扱う。
4. 音声の生成はサーバー側で行い、フロント（`index.html`）は生成済みの音声を再生するだけにする。

## 帰結

- 決定 3 の条件で候補が絞られる。候補は、アクセントを句・音ごとに編集できる合成エンジン（自前でサーバーを立てるもの）と、発音記号やアクセント指定を受け付けるクラウドの音声合成 API。
  自前サーバーは Vercel の関数では動かせず、別のホストが要る。どちらにするかは月額予算の相談の後に決める。
- ADR 0002（npm 依存とビルド工程を持たない）の範囲で、音声エンジンは fetch で呼ぶ外部サービスとして扱う。
- 声の権利が決まるまでは、エンジンに付属する利用条件の範囲の声で試作し、放送局のキャラクター名を付けて外に出さない。
- 録音の「生の音」は持たないため、正確さはアクセント指定と辞書の監修の質で決まる。聞いて不自然な語は辞書側で直す運用になる。

## 却下案

- 録音だけにする: 話速・高さを変えられず、入力した任意の文章を読めない。
